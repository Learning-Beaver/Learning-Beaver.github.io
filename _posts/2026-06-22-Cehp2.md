# AWS S3, NHN Object Storage, MinIO, Ceph 차이점 정리
앞서 Ceph 관련 내용을 정리하다 보니, 이러한 차이점을 정리해 놓는 것이 좋을 것 같았다.

Object Storage를 공부하다 보면 다음과 같은 기술들을 자주 만나게 된다.

* AWS S3
* NHN Object Storage
* MinIO
* Ceph

처음에는 모두 비슷한 기술처럼 보인다.

실제로 모두 Object Storage를 제공하고, S3 API를 지원하며, 데이터 레이크나 AI 플랫폼 구축 시 자주 활용된다.

하지만 자세히 살펴보면 서비스와 소프트웨어라는 큰 차이가 존재한다.

이번 글에서는 AWS S3, NHN Object Storage, MinIO, Ceph의 특징과 장단점을 정리해 보려고 한다.

# AWS S3

AWS에서 제공하는 대표적인 Object Storage 서비스다.

사용자는 버킷을 생성하고 데이터를 저장하기만 하면 된다.

서버, 디스크, 네트워크, 장애 대응 등 인프라 운영은 모두 AWS가 담당한다.

```text
Application
      ↓
    AWS S3
      ↓
 AWS가 운영
```

## 장점

* 서버 및 스토리지 운영이 필요 없음
* 높은 내구성과 안정성 제공
* 사실상 무제한 확장 가능
* AWS 서비스와 뛰어난 연계성

## 단점

* 사용량에 따른 비용 발생
* AWS 환경에 대한 의존성 존재
* 내부 저장 구조를 직접 제어하기 어려움

---

# NHN Object Storage

NHN Cloud에서 제공하는 S3 호환 Object Storage 서비스다.

기본적인 사용 방식은 AWS S3와 매우 유사하다.

```text
Application
      ↓
NHN Object Storage
      ↓
 NHN Cloud가 운영
```

## 장점

* 인프라 운영 부담이 없음
* S3 API 지원
* NHN Cloud 서비스와 연계 가능
* 공공기관 및 국내 CSP 환경에서 활용 가능

## 단점

* 클라우드 서비스 비용 발생
* AWS 대비 글로벌 생태계가 상대적으로 작음
* 서비스 제공 범위 내에서만 사용 가능

---

# MinIO

MinIO는 Object Storage 구축을 목적으로 개발된 오픈소스 소프트웨어다.

S3 API와 높은 호환성을 제공하며, 비교적 간단하게 구축할 수 있다.

```text
Application
      ↓
    MinIO
      ↓
서버 + 디스크
```

## 장점

* 설치 및 운영이 비교적 단순함
* 높은 성능 제공
* S3 API와 높은 호환성
* Kubernetes 환경과 궁합이 좋음

## 단점

* Object Storage 기능만 제공
* Block Storage 및 File Storage 미지원
* 대규모 분산 스토리지 플랫폼 기능은 제한적

---

# Ceph

Ceph는 Object Storage를 포함하여 Block Storage와 File Storage까지 제공하는 오픈소스 분산 스토리지 플랫폼이다.

```text
             Ceph
                │
    ┌───────────┼───────────┐
    │           │           │

 Object      Block       File
 Storage    Storage    Storage
```

단순한 Object Storage 솔루션이라기보다 종합 스토리지 플랫폼에 가깝다.

## 장점

* Object, Block, File Storage 통합 제공
* 뛰어난 확장성
* 강력한 고가용성 제공
* 대규모 스토리지 환경 구성 가능

## 단점

* 구축 난이도가 높음
* 운영 및 장애 대응이 복잡함
* 학습 비용이 높음

# 정리

Object Storage를 공부하면서 가장 헷갈렸던 부분은 AWS S3, NHN Object Storage, MinIO, Ceph를 모두 같은 종류의 기술이라고 생각했던 점이었다.

하지만 실제로는 다음과 같이 구분하는 것이 더 정확하다.

```text
AWS S3
= AWS가 제공하는 Object Storage 서비스

NHN Object Storage
= NHN Cloud가 제공하는 Object Storage 서비스

MinIO
= 직접 구축하는 Object Storage 소프트웨어

Ceph
= Object, Block, File Storage를 제공하는 분산 스토리지 플랫폼
```

즉, AWS S3와 NHN Object Storage는 사용자가 서비스를 이용하는 형태이고,

MinIO와 Ceph는 사용자가 직접 구축하고 운영하는 형태이다.

또한 MinIO는 Object Storage에 집중된 솔루션인 반면, Ceph는 Object Storage를 포함한 종합 분산 스토리지 플랫폼이라는 점에서 차이가 있다.

Object Storage를 검토하고 있다면 단순히 "무엇이 더 좋은가?" 보다는 "어떤 방식으로 운영할 것인가?"를 먼저 고민해 보는 것이 중요할 것 같다.
